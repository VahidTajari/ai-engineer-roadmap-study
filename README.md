# مسیر یادگیری AI Engineer

این ریپو برای یادگیری مرحله‌به‌مرحله‌ی رودمپ **AI Engineer** ساخته شده است.

هدف این پروژه این است که هر روز یک بخش از رودمپ به‌صورت کامل مطالعه شود و خروجی آن به شکل زیر نگهداری شود:

- یک فایل HTML تعاملی برای مرور سریع کل مسیر
- یک فایل Markdown جداگانه برای هر درس تکمیل‌شده
- خلاصه‌ی نکات کلیدی هر بخش
- فلش‌کارت برای مرور
- آزمون پایان هر درس
- ثبت تدریجی پیشرفت یادگیری

## ساختار ریپو

```text
.
├── README.md
├── index.html
└── lessons
    └── 01-introduction.md
```

## فایل تعاملی

فایل `index.html` مرجع اصلی مرور کل دوره است و با تکمیل هر بخش به‌روزرسانی می‌شود.

این فایل شامل موارد زیر است:

- فهرست بخش‌های رودمپ
- وضعیت پیشرفت
- محتوای درس‌ها
- فلش‌کارت‌ها
- یادداشت‌های شخصی
- امکان علامت‌زدن بخش‌های تکمیل‌شده

## روش به‌روزرسانی

پس از تکمیل هر درس:

1. محتوای کامل درس در پوشه‌ی `lessons/` به‌صورت Markdown اضافه می‌شود.
2. خلاصه و فلش‌کارت‌های همان درس به `index.html` اضافه می‌شود.
3. وضعیت پیشرفت در فایل HTML به‌روز می‌شود.
4. تغییرات در GitHub commit و push می‌شوند.
